# Резюме

LaTeX-конструктор резюме. Проект позволяет держать несколько резюме под разные роли (backend, devops и др.), собирая их из общего набора блоков: разделов резюме и записей об опыте и достижениях.

## Структура проекта

```
.
├── backend.tex      # резюме backend-разработчика (одно резюме = один основной .tex-файл)
├── preamble.tex     # пакеты, поля, шрифты, языки, ссылки
├── config.tex       # личные данные (ФИО, GitHub, Telegram, email) и выбор шрифтов под ОС
├── macros.tex       # цвета и команды оформления (\cvsection, \cvproject и др.)
├── sections/        # разделы резюме: шапка, образование, навыки, приложение
└── items/           # записи об опыте и достижениях — по одной на файл
```

- **Основные `.tex`-файлы** (`backend.tex`, `devops.tex`, …) — это сами резюме. Своего текста в них нет: они только подключают нужные разделы из `sections/` и записи из `items/` в нужном порядке.
- **`sections/`** — разделы резюме. Общие разделы (шапка, образование, приложение) используются во всех резюме, а разделы под конкретную роль получают суффикс: `skills-backend.tex`, `skills-devops.tex`.
- **`items/`** — общий набор проектов и достижений. Одну запись можно подключить в нескольких резюме и под разными заголовками («Релевантный опыт», «Достижения» и т.д.).

## Сборка

Нужен **XeLaTeX** (проект использует `fontspec` и `polyglossia`, pdflatex не подойдёт). Шрифты: Liberation Serif / Liberation Mono на Linux, Times New Roman / Courier New на других ОС.

```sh
mkdir -p build
xelatex -output-directory=build backend.tex
xelatex -output-directory=build backend.tex
```

Готовый PDF появится в `build/backend.pdf`. Чтобы собрать другое резюме, передайте вместо `backend.tex` его файл.

В VS Code с расширением LaTeX Workshop можно использовать готовые настройки из `.vscode/.settings-for-linux.json` или `.vscode/.settings-for-macos.json` (рецепт по умолчанию — `xelatex x 2`, вывод в `build/`).

## Как создать новое резюме

1. **Скопируйте существующее резюме** под новую роль — старое при этом остаётся:

   ```sh
   cp backend.tex devops.tex
   ```

2. **Добавьте разделы под роль**, если они отличаются. Например, навыки:

   ```latex
   % sections/skills-devops.tex
   % Технические навыки devops
   \cvsection{Технические навыки}
       Linux, Docker, Kubernetes, Ansible, Terraform, CI/CD.
   ```

3. **Добавьте новые записи об опыте и достижениях** в `items/`, если нужных ещё нет. Каждый файл — один пункт списка:

   ```latex
   % items/my-project.tex
   % Краткое описание записи
   \item \cvproject{Название проекта}{Технологии}
       Задача: ...\\
       Стек: ...\\
       Результат: ...
   ```

   Необязательная пометка выводится рядом с названием: `\cvproject[личный проект]{Название}{Технологии}`.

4. **Соберите резюме в новом файле** из нужных блоков:

   ```latex
   \documentclass[11pt]{article}
   \input{preamble}

   \begin{document}
       \input{sections/header}
       \input{sections/education}
       \input{sections/skills-devops}

       \cvsection{Релевантный опыт}
       \begin{cvlist}
           \input{items/my-project}
           \input{items/webrtc}
       \end{cvlist}

       \cvsection{Достижения}
       \begin{cvlist}
           \input{items/school21}
       \end{cvlist}

       \input{sections/appendix}
   \end{document}
   ```

5. **Соберите PDF** (см. [Сборка](#сборка)) и проверьте, что резюме помещается на одну страницу.

Личные данные (ФИО, ссылки, почта) меняются в `config.tex` — они общие для всех резюме.

## Оформление

Команды из `macros.tex`:

| Команда | Назначение |
|---|---|
| `\cvsection{Заголовок}` | заголовок раздела с красной линией |
| `\cventry{Слева}{Справа}` | строка «название — период», например для образования |
| `\cvproject[пометка]{Название}{Технологии}` | строка проекта/достижения |
| `\cvsubtext{Текст}` | второстепенный серый курсив |
| `cvlist` | компактный нумерованный список для записей из `items/` |

## Стиль разметки

- Отступы обязательны и отражают вложенность (один уровень — 4 пробела): содержимое окружений (`document`, `cvlist`, `center`, …) сдвигается на уровень внутрь, текст раздела — под `\cvsection{...}`, текст записи — под строку `\item`.
- Каждый `.tex`-файл начинается с краткого комментария `%` о своём назначении.
