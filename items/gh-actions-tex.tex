% Выстраивание CI/CD-пайплайнов с помощью GitHub Actions
\item \cvproject[Личный проект]{Конвейеры CI/CD на GitHub Actions}{GitHub Actions}
    Задача: Автоматизировать сборку и проверку изменений в репозитории шаблона документов.\\
    Стек: GitHub Actions, GitHub Secrets, YAML.\\
    Результат: Четыре независимых конвейера: сборка PDF при каждом push и запросе на слияние, автоматическая проверка изменений и актуальности документации, запуск AI-агента по упоминанию.
