% Сетевая настройка виртуальной машины
\item \cvproject{Настройка сети виртуальной машины}{Ubuntu Server}
    Задача: Настроить локальную сеть между виртуальными машинами, маршрутизацию, доступ по ssh и firewall.\\
    Стек: Netplan, iptables, iperf3, ipcalc.\\
    Результат: Локальная сеть с настроенной маршрутизацией между подсетями.
